# Task Manager Backend Design

This project contains the backend system design for a simple Task Manager application.

The project covers:

- REST API design
- GraphQL API design
- gRPC service design
- PostgreSQL database design
- JWT authentication strategy
- Docker-based PostgreSQL setup
- Postman API collection
- OpenAPI/Swagger specification
- API versioning strategy
- Database indexing strategy

No application/backend code is implemented. This project focuses on system and API design, database design, documentation, and local infrastructure setup.
